# Contributing

Contributions are welcome via pull requests on [GitHub](https://github.com/hyrograsper/lunar-fortis).

## Setup

```bash
composer install
composer test
```

## Guidelines

- Follow [PSR-12](https://www.php-fig.org/psr/psr-12/) coding standards (enforced by Pint).
- Write tests for new functionality.
- Run `composer quality` before submitting (formats, analyses, and tests).

## Pull Requests

1. Fork the repository and create a feature branch from `main`.
2. Add or update tests to cover your changes.
3. Ensure `composer quality` passes.
4. Submit a pull request with a clear description of the change.

## Security

Please do **not** open a GitHub issue for security vulnerabilities. See [SECURITY.md](SECURITY.md) for the responsible disclosure process.
